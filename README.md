# 彈珠勇者：素材庫與 3.x 企劃稿

這個分支**不會部署**，也不會合併進 main。內容如下：

- `packs/`：66 包免費商用素材，包括角色、怪物、魔王、裝備圖示、技能特效、UI、背景、BGM、音效和字型。每包都附 `LICENSE.txt`，寫明來源、作者、授權與署名文字。
- `previews/`：各包的預覽圖。
- `CATALOG-assets-sprites.md`：角色、怪物、魔王、裝備、特效、坐騎的素材目錄。
- `CATALOG-assets-ui-audio.md`：UI、扭蛋演出、貨幣、背景、BGM、音效、字型的素材目錄。
- `LICENSES-SUMMARY.md`：授權總表。
- `plan/`：四份詳細設計稿（經濟扭蛋、英雄裝備、新模式關卡、數值平衡），以及平衡試算腳本。

授權原則：只收 CC0、CC-BY、OFL 三種授權，而且必須允許在公開 repo 重新散布。CC-BY 的素材正式使用時，要放進 `assets/licenses/` 並在遊戲內 Credits 列出作者。
